# Hi, I'm pytraveler 👋

**Building practical tools for local AI.**

I develop open-source software that makes local AI easier to use, automate, and manage.

My projects range from ComfyUI extensions and generative AI workflows to desktop applications, MCP integrations, and tools for running local language models.

## Featured projects

| Project | Description |
|---|---|
| [MiniMax-H3 Prompt Rewriter for ComfyUI](https://github.com/pytraveler/MiniMax-H3-Prompt-Rewriter-ComfyUI) | Local prompt rewriting and multimodal reference processing for AI video and audio generation. |
| [Corrallama](https://github.com/pytraveler/LlamaServerLauncherAvalonia) | Cross-platform desktop application for managing llama.cpp servers, models, benchmarks, and configurations. |
| [Breeze for ComfyUI](https://github.com/pytraveler/ComfyUI-Breeze) | Frontend extensions for clearer, more navigable ComfyUI workflows, with graph visualization, smart connections, execution tracking, and workflow inspection. |

| [YuE2-ComfyUI](https://github.com/pytraveler/YuE2-ComfyUI) | AI music generation in ComfyUI with score editing, audio/MIDI workflows, and track editing. |
| [ComfyUI Safe Updater](https://github.com/pytraveler/comfyui-safe-updater) | Update portable ComfyUI installations with checkpoints and rollback support. |
